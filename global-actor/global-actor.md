### 글로벌 액터는 왜 필요한가?

기존 액터의 격리 범위를 하나의 인스턴스에서 여러 타입, 함수, 프로퍼티로 확장하기 위해 도입되었다.

기존에는 해당 액터 내부에 있는 데이터만 보호했다면, 이제는 액터 외부에 있는 데이터들도 이것을 통해서 보호할 수 있다.

---

### 글로벌 액터는 왜 싱글톤 방식인가?

```swift
@globalActor
struct DatabaseActor {
    actor ActorType {}

    static let shared = ActorType()
}
```

액터의 격리는 액터 타입 자체에서 격리가 생기는 것이 아니라, 인스턴스별로 격리가 부여되기 때문이다. 그렇기 때문에 `shared` 가 제공하는 격리로 사용된다.
